## 真假住宅 IP：两种说法并存，验法只有一个

这个行业里对“静态住宅 IP 到底是什么”有两种完全对立的说法，都值得你知道。

一种说法来自 SGER 的实测报告，原话很直白：

> 市面上所有所谓的静态住宅IP本质上都是“机房托管ISP”（广播机房IP挂载了运营商ISP属性），优点是固定长效、性价比高。

按这个说法，你买到的机器物理上还在机房里，只是它的 IP 段登记在运营商名下，查询时显示成宽带用户。

另一种说法来自服务商的推广文。比如丽萨主机的宣传页面写“所有硬件托管在美国真实民房内，向当地宽带运营商申请安装光纤宽带”，还强调“不只是‘看起来像住宅’，而是物理上就托管在美国民房里”。这类产品通常被单独叫作“家宽 VDS”，价格也比同配置的机房住宅 IP 贵一倍左右。

哪种是真的？两种产品在市场上都存在。问题在于销售页面基本不会主动告诉你自己属于哪一类，只能自己查。六六云对美西这条线的官方表述是“双 ISP 属性”“全新纯净 IP 池”，没有直接说物理托管在民房。下单前用 ASN 和欺诈分验一遍，比看任何宣传语都可靠。

顺手厘清几个容易被绕晕的词。原生 IP 指 IP 的注册地和服务器实际所在地一致，广播 IP 则是注册地在 A 国、机器在 B 国。双 ISP 指这个 IP 同时带有两家运营商的属性标记，查询结果看起来更接近真实宽带用户。家宽 VDS 是把整台机器放进民房、走当地家庭宽带线路，成本最高。按照 GetIPProxy 的说法，业务要求注册地与定位地一致就选原生，更看重可选地区和成本、不强求原生信号就选广播。

验真分三步走：

1. 拿到 IP 后，用 IPinfo 查它的 ASN 和类型，类型字段必须是 `isp`。
2. 用 Scamalytics 输入这个 IP，看 Fraud Score，20 分以下算低风险。
3. 挂上你实际的业务环境做小规模连接测试，别一上来就买年付。

有一个坑要提前说。SGER 提示，部分低价“静态住宅 IP”并非服务商合法向运营商申请的 IP 段，而是通过灰色 SDK 或代理软件占用真实用户设备的网络出口。小红书、闲鱼上那些远低于市场价的货，很多是几十个人共用一个出口的共享 IP，其中一人滥用，整段 IP 一起进黑名单。你花钱买的是干净的历史记录，这一点在低价货上通常没有。

### 静态住宅 IP 会自动换 IP 吗？

不会。静态的意思就是整个租用周期内出口地址固定不变，今天登录和三个月后登录，平台看到的是同一个地址。需要每次连接都换 IP 的是动态住宅代理，那类产品适合爬虫和数据采集，跟账号维护是两条路。

### 欺诈分 0 分就一定是好 IP 吗？

不一定。SGER 自己也在报告里提醒，Fraud Score 只是风险数据库里的一个维度，还要结合 ASN、运营组织、AS 类型、地理位置和实际连接表现一起看，不同数据库还可能给出不同分类。分数低是入场券，不是通行证。

### 双 ISP 和原生 IP 有什么区别？

原生 IP 说的是 IP 注册地和机器实际所在地一致，解决的是“归属地对不对”。双 ISP 说的是这个 IP 同时带两家运营商的属性标记，解决的是“看起来像不像真实宽带用户”。两个概念不冲突，可以同时成立，买之前分开确认。

### 流量是单向算还是双向算？

六六云这几条住宅线标的是双向统计，上传下载都扣额度。这一点在视频、直播、大文件传输场景下差别很大，下单前按自己业务的月上传量估一遍。有些服务商的流量版是单向计费，不能直接拿两家的标称流量做横向比较。

### 买到的 IP 和标称地区不一致怎么办？

静态住宅 IP 的地区库存会随套餐和时间变化。下单前确认目标国家或城市是否可选，拿到 IP 后立刻用第三方数据库核对实际定位，发现明显不符就走工单找客服。这也是建议先月付的原因之一，别在没验货的情况下付一年。
